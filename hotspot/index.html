    Buku Panduan

    1. Mengenal Fikri Tools Mikrotik

    Aplikasi ini digunakan untuk melihat, mengubah, dan mengemas template halaman login hotspot MikroTik langsung di peramban. Semua proses dilakukan di perangkat Anda, tidak ada file yang dikirim ke server.

    1BukaUnggah ZIP/RAR atau buat tampilan baru
    2PratinjauLihat di ponsel, tablet, atau desktop
    3SuntingUbah kode dan gambar, hasil langsung tampil
    4UnduhSimpan ZIP/RAR atau gambar JPG

    2. Langkah cepat

    Buka template. Seret berkas ZIP atau RAR ke kotak unggah, atau tekan Pilih file. Berkas harus berisi login.html.
    Pilih halaman. Buka panel Halaman lalu pilih login.html, status.html, dan seterusnya untuk melihat tiap tampilan.
    Pilih perangkat. Ganti ukuran layar pratinjau di panel Perangkat (Ponsel, Tablet, Desktop).
    Ubah kode. Tekan mode Split agar kode dan pratinjau tampil berdampingan. Setiap perubahan langsung terlihat.
    Unduh hasil. Tekan Unduh ZIP / RAR, lalu unggah isinya ke router (lihat bab 11).
    Belum punya template? Tekan Buat tampilan baru untuk membuat template lengkap dengan pengaturan warna, gambar, dan fitur login (bab 8).

    3. Peta tata letak layar

    Angka pada gambar sesuai dengan keterangan di bawahnya.

    • 1Tombol menu. Membuka Buku Panduan, Setting, dan Credit.
    • 2Pilih file dan Buat tampilan baru. Tombol untuk memulai proyek. Setelah proyek terbuka, area ini mengecil di bagian atas.
    • 3Panel samping. Berisi pilihan halaman, perangkat, opsi preview, Hapus $, unduhan, dan struktur file.
    • 4Mode tampilan. Preview, Editor, atau Split.
    • 5Editor kode. Ketuk untuk membuka dan mengubah kode atau gambar.
    • 6Pratinjau. Menampilkan halaman seperti yang dilihat pengguna hotspot.
    • 7Zoom. Membuka pratinjau layar penuh dan fitur Unduh JPG.

    4. Panel samping

    Setiap bagian dapat dilipat. Ketuk judulnya untuk membuka isinya.

    login.htmlstatus.html

    Unduh ZIP / RAR

    6. Editor kode dan gambar

    Buka editor dengan mode Editor atau Split, lalu ketuk bagian Kode untuk membuka isinya. Setiap perubahan langsung diterapkan ke pratinjau.

    login.html
    Pilih file. Memilih file yang akan diedit. File yang sudah diubah diberi keterangan (diubah).
    File baru
    Membuat file baru. Ketik nama berekstensi html, css, js, txt, svg, atau json, lalu tekan Tambah.
    Hapus
    Menghapus file yang sedang dibuka. Hanya berlaku untuk file buatan sendiri atau proyek baru.
    Reset
    Mengembalikan file ke isi aslinya.
    Salin
    Menyalin isi file ke papan klip.
    Unduh
    Membuka pilihan unduh ZIP atau RAR.

    Bagian Gambar

    Tambah gambar
    Menambahkan gambar baru ke folder img/. Gunakan di kode dengan src="img/nama.png".
    GantiResetHapus
    Ganti menimpa gambar dengan file lain (format menyesuaikan nama aslinya). Reset mengembalikan gambar asli. Hapus hanya tersedia untuk gambar yang Anda tambahkan.
    Tips. Tombol Tab menyisipkan spasi. Untuk berpindah fokus dengan keyboard, tekan Esc lalu Tab. Gunakan gambar berukuran kecil agar router memuatnya dengan cepat.

    7. Zoom dan unduh JPG

    Tombol Zoom membuka pratinjau layar penuh. Dari sini Anda dapat menyimpan tampilan sebagai gambar JPG yang sama dengan pratinjau.

    • 1Pilih halaman. Berpindah halaman tanpa menutup zoom.
    • 2Pilih perangkat. Ponsel, Tablet, atau Desktop. Ukuran ini juga menjadi ukuran gambar JPG.
    • 3Zoom. Tombol minus dan plus mengubah skala, Pas menyesuaikan dengan layar.
    • 4Seluruh halaman. Aktif: seluruh tinggi halaman disimpan. Nonaktif: hanya area layar perangkat.
    • 5Unduh JPG. Menyimpan hasil render dengan nama nama-proyek-halaman-perangkat.jpg. Tombol Tutup di sebelahnya menutup tampilan zoom.
    Hasil JPG sama dengan pratinjau. Halaman digambar langsung ke kanvas sehingga warna latar, gambar, dan teks ikut tersimpan, termasuk di Safari dan iPhone. Tinggi halaman dibatasi hingga 12.000 piksel.

    8. Membuat tampilan baru

    Tekan Buat tampilan baru. Pilih Template lengkap (semua halaman siap pakai) atau Kosong, dari nol (hanya login.html dan style.css).

    • 1Isian dasar. Nama proyek, judul, subjudul, footer, gaya tema, dan warna aksen.
    • 2Pengaturan lanjutan. Gaya lanjutan, daftar halaman, fitur login, dan gambar.
    • 3Pratinjau langsung. Setiap perubahan tampil seketika. Gambar dapat digeser langsung di sini.

    Gaya lanjutan

    • Warna latar, kartu, dan teks. Bebas diubah. Warna garis dan kolom input menyesuaikan otomatis.
    • Jenis latar. Warna polos atau gradasi dua warna dengan sudut yang dapat diatur.
    • Font. Sistem, Serif, Klasik, Mono, atau Bulat. Hanya font bawaan perangkat agar tetap berjalan tanpa internet.
    • Kartu. Sudut, lebar, transparansi, efek kaca (blur), tebal garis tepi, dan bayangan.
    • Tombol dan input. Sudut dan tinggi. Judul. Ukuran dan perataan teks.

    Pengaturan gambar

    Tekan Tambah gambar untuk memasukkan satu atau beberapa gambar. Setiap gambar punya panel sendiri yang dapat dibuka.

    Latar penuhLogo kartuStiker bebasBanner bawah
    Preset cepat. Satu ketukan mengatur tempat, ukuran, dan posisi yang umum dipakai.
    Penempatan
    Pilih tempat: latar belakang, di atas judul, di bawah form, atau bebas. Atur halaman tampil (semua halaman atau hanya login), lebar, rata, geser, posisi, dan lapisan depan atau belakang kartu.
    Bentuk
    Putar (derajat), balik horizontal atau vertikal, sudut bulat, serta garis tepi lengkap dengan warnanya.
    Warna dan efek
    Transparansi, blur, kecerahan, kontras, saturasi, abu-abu, sepia, putar warna, bayangan, dan mode campuran warna.
    Animasi
    Melayang, berdenyut, berputar, atau berkedip lembut, dengan durasi yang dapat diatur.
    NaikTurunDuplikatGanti gambarResetHapus
    Mengatur urutan tumpukan (layer), menggandakan, mengganti file gambar tanpa kehilangan pengaturan, mengembalikan pengaturan awal, atau menghapus. Kotak Tampilkan menyembunyikan gambar sementara.
    Geser langsung. Seret gambar di pratinjau untuk memindahkannya. Ketuk sekali pada gambar untuk membuka panel pengaturannya.

    9. Hapus tanda $

    Tombol Hapus $ menghapus setiap karakter $ di file html, css, js, txt, svg, dan json. Hasilnya dapat dibatalkan dengan tombol Urungkan selama paket belum diganti.

    Sebelum
    <input value="$(username)"> $(if error)...$(endif)
    Sesudah
    <input value="(username)"> (if error)...(endif)
    Perhatian. Variabel MikroTik seperti $(username) tidak lagi diisi router setelah tanda $ dihapus. Gunakan fitur ini hanya bila memang diperlukan.

    10. Variabel MikroTik yang didukung pratinjau

    Pratinjau mengisi variabel berikut dengan data contoh, termasuk blok $(if ...), $(elif ...), $(else), dan $(endif).

    VariabelArti
    $(username)Nama pengguna yang sedang login
    $(ip), $(mac)Alamat IP dan MAC perangkat pengguna
    $(uptime)Lama sesi berjalan
    $(session-time-left)Sisa waktu sesi
    $(bytes-in-nice), $(bytes-out-nice)Jumlah data diunduh dan diunggah
    $(remain-bytes-total-nice)Sisa kuota
    $(link-login-only)Alamat tujuan pengiriman form login
    $(link-orig)Alamat situs yang dituju pengguna semula
    $(link-status), $(link-logout), $(link-redirect)Tautan ke halaman status, logout, dan pengalihan
    $(error)Pesan kesalahan dari router
    $(chap-id), $(chap-challenge)Data untuk login CHAP (diisi bila opsi Login CHAP aktif)

    11. Memasang template ke router

    Unduh arsip. Tekan Unduh ZIP / RAR, lalu ekstrak. Anda akan mendapatkan folder hotspot.
    Cadangkan. Di Winbox buka Files, lalu salin folder hotspot lama sebagai cadangan.
    Unggah. Seret isi folder hotspot baru ke folder hotspot di router (atau gunakan FTP).
    Arahkan profil. Buka IP > Hotspot > Server Profiles, pilih profil, lalu pada tab General isi HTML Directory dengan hotspot.
    Uji. Sambungkan perangkat ke WiFi hotspot dan pastikan halaman login baru muncul.

    Atau lewat terminal:

    # arahkan profil ke folder template /ip hotspot profile set [find name=hsprof1] html-directory=hotspot # aktifkan metode login yang dipakai template /ip hotspot profile set [find name=hsprof1] login-by=http-chap,http-pap
    Catatan CHAP. Bila template memakai md5.js, pastikan file tersebut ikut terunggah dan metode login http-chap aktif.

    12. Menu: Setting, Credit, dan Donasi

    Tombol bergaris tiga di pojok kiri atas. Membuka menu berisi Buku Panduan, Setting, dan Credit.
    Setting
    Tema (gelap atau terang), ketebalan font seluruh tampilan, hapus cache data sementara, dan tombol Donasi. Tema dan ketebalan font tersimpan di peramban.
    Credit
    Informasi aplikasi, pengembang (Fikri Everly), dan studio (CaxaStudio).
    Donasi
    Menampilkan kode QR untuk mendukung pengembangan. Tombol Unduh QR menyimpan kode QR sebagai gambar PNG.

    13. Pertanyaan dan masalah umum

    Gambar tidak muncul di pratinjau

    Periksa nama dan huruf besar-kecil pada src atau url(). Di panel Struktur file, rujukan yang salah ditandai merah dengan keterangan tidak ditemukan.

    Hasil JPG hitam atau kosong

    Pastikan Anda memakai versi terbaru aplikasi ini. Gambar yang dimuat dari situs lain (alamat https) dan tidak mengizinkan akses silang tidak dapat ikut tersimpan. Simpan gambar tersebut ke dalam folder img/ proyek.

    File RAR tidak terbuka

    RAR tanpa kompresi dibaca langsung. RAR terkompresi membutuhkan koneksi internet untuk memuat pustaka pembuka. RAR berpassword harus disimpan ulang tanpa password. Bila tetap gagal, gunakan ZIP.

    Pratinjau tidak berubah setelah mengetik

    Pastikan file yang diedit sama dengan halaman yang sedang dipilih di panel Halaman. File seperti style.css memengaruhi semua halaman yang memakainya.

    Tombol pada halaman tidak berpindah halaman

    Di pratinjau, tautan ke login, status, dan logout berpindah antarhalaman bila file tujuannya ada di paket. Tautan keluar hanya menampilkan keterangan di bawah pratinjau.

    Apakah data saya diunggah ke server?

    Tidak. Seluruh pembacaan, pengeditan, dan pengemasan terjadi di peramban Anda.

    Hapus semua tanda $

    Menghapus setiap karakter $ di seluruh file teks (html, css, js, txt, svg, json) pada paket yang sedang dibuka.

    Variabel MikroTik seperti $(username) akan menjadi (username) dan tidak lagi terisi oleh router. Kamu bisa membatalkannya dengan Urungkan.

    Unduh proyek

    Pilih format arsip. Isinya sama, semua file ada di dalam folder hotspot/.
