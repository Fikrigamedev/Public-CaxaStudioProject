    Pratinjau login (geser gambar langsung di sini)

    Hapus semua tanda $

    Menghapus setiap karakter $ di seluruh file teks (html, css, js, txt, svg, json) pada paket yang sedang dibuka.

    Variabel MikroTik seperti $(username) akan menjadi (username) dan tidak lagi terisi oleh router. Kamu bisa membatalkannya dengan Urungkan.

    Unduh proyek

    Pilih format arsip. Isinya sama, semua file ada di dalam folder hotspot/.
